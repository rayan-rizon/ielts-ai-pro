# **DIMENSION 5 — Back-end Prompt Optimization**

The five critical failures documented in this audit trace to specific, identifiable gaps in the System Instructions. All are fixable. The following section diagnoses each gap and provides a precise, high-impact System Instruction tweak ready for implementation.

## **FIX #1 — Speaking Modality Gate**

**ROOT CAUSE: The AI assigns a Pronunciation band from text input. No instruction exists to gate the pronunciation criterion on audio availability.**

|                                                                                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **System Instruction to Add**                                                                                                                     |
| SPEAKING — PRONUNCIATION SCORING RULE:                                                                                                            |
| You may ONLY assign a Pronunciation band if audio input has been provided. If the speaking input is text-only (transcript), you MUST:             |
| 1\. Omit the Pronunciation band from the score table entirely.                                                                                    |
| 2\. Replace it with a note: 'Pronunciation cannot be assessed from a text transcript. Submit an audio recording to receive a Pronunciation band.' |
| 3\. Adjust the Overall Speaking band to reflect only the three scoreable criteria.                                                                |
| 4\. Do NOT estimate or infer pronunciation quality from the vocabulary or grammar of the text.                                                    |

## **FIX #2 — Speaking Length Calibration Floor**

**ROOT CAUSE: No minimum response-length floor exists for Speaking band assignment. Fluency and LR scores are awarded without reference to the quantity of speech produced.**

|                                                                                                                                                                                                                  |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **System Instruction to Add**                                                                                                                                                                                    |
| SPEAKING — MINIMUM LENGTH REQUIREMENTS:                                                                                                                                                                          |
| Before assigning Fluency or Lexical Resource bands, verify response length against these floors:                                                                                                                 |
| • Part 1: Each answer should be 40–80 words (2–4 sentences). Answers under 30 words = cap Fluency at Band 4.                                                                                                     |
| • Part 2: Monologue should be 120–200 words (~60–90 seconds). Responses under 80 words = cap Fluency at Band 4.                                                                                                  |
| • Part 3: Each answer should be 60–120 words. Under 40 words = cap Fluency at Band 4.                                                                                                                            |
| If a candidate falls below the floor in any part, explicitly state the shortfall in feedback: '\[Part X\] response was approximately \[N\] words — below the expected minimum. Fluency band capped accordingly.' |

## **FIX #3 — No-Fabrication Rule for Visual Prompt Corrections**

**ROOT CAUSE: When a student misidentifies a visual prompt type, the AI generates 'corrective' sample sentences using invented data it cannot have sourced from the actual image.**

|                                                                                                                                                                                                    |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **System Instruction to Add**                                                                                                                                                                      |
| TASK 1 CORRECTIONS — FABRICATION PROHIBITION:                                                                                                                                                      |
| When a candidate has responded to the wrong visual type (e.g., describes a bar chart instead of a map), you MUST NOT:                                                                              |
| • Invent specific details from the actual visual (roads, percentages, building names, directions, dates).                                                                                          |
| • Produce a 'corrected' sentence containing data you have not been explicitly given.                                                                                                               |
| Instead, provide a STRUCTURAL TEMPLATE using placeholder language:                                                                                                                                 |
| Example: 'The maps show \[primary change\] between \[year 1\] and \[year 2\]. For instance, \[feature A\] was \[changed/added/removed\] in the \[location descriptor\].'                           |
| Always mark template sentences as structural models, not content models. Append: '(Note: fill in the actual data from the maps provided — do not use these as factual statements about the maps.)' |

## **FIX #4 — Essay-Type Classification Pre-Check**

**ROOT CAUSE: The AI does not explicitly classify the Task 2 prompt type before evaluating the response, causing it to miss essay-structure failures.**

|                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **System Instruction to Add**                                                                                                                                                                                                                                                                          |
| TASK 2 — MANDATORY PROMPT-TYPE CLASSIFICATION:                                                                                                                                                                                                                                                         |
| Before scoring any Task 2 response, first identify the prompt type from this taxonomy:                                                                                                                                                                                                                 |
| • Opinion Essay ('To what extent do you agree/disagree?' or 'Do you agree or disagree?')                                                                                                                                                                                                               |
| • Discussion Essay ('Discuss both views and give your own opinion')                                                                                                                                                                                                                                    |
| • Problem/Solution Essay ('What are the causes of X? What solutions can be suggested?')                                                                                                                                                                                                                |
| • Advantage/Disadvantage Essay ('What are the advantages and disadvantages of X?')                                                                                                                                                                                                                     |
| • Two-Part Question Essay ('Why is X? Do you think Y?')                                                                                                                                                                                                                                                |
| Then check: does the candidate's essay structure match the required format for that prompt type?                                                                                                                                                                                                       |
| • Opinion Essay: body paragraphs must primarily argue FOR the stated position. A 50/50 structure = Task Achievement penalty. Flag explicitly: 'Your essay reads as a discussion of both sides rather than a sustained argument for your stated position. This will limit your Task Achievement score.' |

## **FIX #5 — Word-Count Verification Module**

**ROOT CAUSE: The AI reported the Task 1 word count as 68 words when the actual count is approximately 85 words. Inaccurate word counts affect band justifications and student trust.**

|                                                                                                                                                                                                                |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **System Instruction to Add**                                                                                                                                                                                  |
| WORD COUNT — MANDATORY VERIFICATION:                                                                                                                                                                           |
| Before writing any feedback, count the words in the candidate's response. Use the following method:                                                                                                            |
| • Count all words including numbers, hyphenated terms (count as one word), and contractions.                                                                                                                   |
| • Report the count as: 'Word count: approximately \[N\] words.'                                                                                                                                                |
| • If the count is under the minimum (150 for Task 1; 250 for Task 2), state the deficit explicitly: 'Your response is approximately \[N\] words — \[X\] words below the minimum \[150/250\]-word requirement.' |
| • Do not use approximate counts to justify over-generous band awards. An under-length response cannot demonstrate the full range of features required for bands 6+.                                            |
| • For Speaking: note the approximate word count of each part's response to calibrate Fluency accurately.                                                                                                       |

## **BONUS FIX #6 — Band 9 Speaking Sample Naturalness Filter**

**ROOT CAUSE: The AI models Band 9 speaking responses using written-register vocabulary that sounds unnatural in a spoken examination context.**

|                                                                                                                                                                               |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **System Instruction to Add**                                                                                                                                                 |
| SPEAKING — BAND 9 SAMPLE RESPONSE REGISTER:                                                                                                                                   |
| When generating Band 9 sample speaking responses, apply the following naturalness filter:                                                                                     |
| • Prefer spoken collocations over literary/academic expressions.                                                                                                              |
| • Include natural discourse markers: 'Well, I'd say...', 'Honestly, I think...', 'It's hard to say exactly, but...'                                                           |
| • Avoid metaphors or abstract phrases that would be highly unusual in spontaneous speech.                                                                                     |
| • After generating a Band 9 sample, ask: 'Could a fluent speaker produce this naturally without a script?' If not — simplify the phrasing while maintaining vocabulary range. |
