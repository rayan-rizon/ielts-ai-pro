# IELTS Vocabulary Master List — 20 Categories, Cross-Checked

<aside>
🎯

**How to use this list.** Learn words in _collocations_, not isolation. Examiners reward accurate, natural word choice over rare words used wrongly. Target ~15 words per category, 3 categories per week, and recycle each word in one Speaking answer plus one Writing Task 2 paragraph.

</aside>

## Analysis: what actually raises the Lexical Resource band

| Band | What the descriptor requires                                                      | Practical implication                             |
| ---- | --------------------------------------------------------------------------------- | ------------------------------------------------- |
| 6.0  | Adequate range; some inaccuracy in word choice                                    | Generic words (_good, bad, big problem_) dominate |
| 7.0  | Some less common vocabulary; some awareness of style and collocation              | Needs topic-specific nouns + precise verbs        |
| 8.0  | Wide range used fluently and flexibly; skilful use of uncommon items; rare errors | Needs collocation accuracy and paraphrase control |
| 9.0  | Full flexibility and precise use                                                  | Word choice sounds inevitable, not decorative     |

**Three evidence-based priorities**

1. **Topic nouns beat fancy adjectives.** _Congestion charge, carbon footprint, recidivism_ signal topic control instantly; _plethora_ and _myriad_ do not.
2. **Collocation errors cost more than limited range.** _Do a mistake_ caps you at 6.0 faster than plain-but-correct wording.
3. **Paraphrase capacity is measurable.** Every Task 2 question must be reworded once in the introduction; each category below gives synonym sets for exactly that purpose.

## 18. Cohesion & discourse markers

## Cross-check notes: accuracy traps I verified

<aside>
⚠️

These are the errors that most often appear in memorised IELTS word lists. Each pair below is genuinely distinct.

</aside>

| Confusable pair                 | Correct distinction                                                                  |
| ------------------------------- | ------------------------------------------------------------------------------------ |
| misinformation / disinformation | Misinformation is false _without_ intent to deceive; disinformation is _deliberate_. |
| epidemic / pandemic             | An epidemic is regional; a pandemic spans countries or continents.                   |
| correlation / causation         | Correlation is association only; causation means one produces the other.             |
| economic / economical           | _Economic_ = relating to the economy; _economical_ = not wasteful, cheap to run.     |
| effect / affect                 | _Effect_ is normally the noun; _affect_ is the verb.                                 |
| practice / practise             | In British English, _practice_ is the noun, _practise_ the verb.                     |
| historic / historical           | _Historic_ = important in history; _historical_ = relating to the past.              |
| continual / continuous          | _Continual_ = repeated with breaks; _continuous_ = unbroken.                         |
| amount / number                 | _Amount_ for uncountables, _number_ for countables.                                  |
| less / fewer                    | _Less_ goes with uncountable nouns; _fewer_ with countable plurals.                  |
| adolescent / child              | _Adolescent_ means roughly 13–19 — do not use it for young children.                 |
| redundancy / redundant          | Noun for the job loss; adjective for the person or thing no longer needed.           |
| stationary / stationery         | _Stationary_ = not moving; _stationery_ = writing materials.                         |
| principle / principal           | _Principle_ = a rule or belief; _principal_ = main, or a head of school.             |
| criterion / criteria            | _Criterion_ is singular; _criteria_ is plural.                                       |
