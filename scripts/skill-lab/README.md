# Practice Lab content

The 72 synthetic clips for the retired standalone Listening lessons have been removed from public/audio/skill-lab. Original library audio is unchanged. Old audio lessons show a retirement message and link to library practice; saved results remain accessible. Do not rebuild the synthetic clips.

Local development opens the library-backed Practice Lab by default. Server rollout settings still control whether new sets can start. Never substitute mock data for authenticated release verification.
