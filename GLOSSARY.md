# Domain glossary

- **Writing evaluation:** Feedback for a learner’s Writing response. A test may include Task 1, Task 2, or both.
- **Evaluation attempt:** One generation of Writing feedback for a session. Retrying a failed evaluation starts a new attempt; rejoining a pending evaluation continues the existing attempt.
- **Partial feedback:** Feedback already produced for an individual Writing task while another task is unfinished or has failed.
- **Evaluation failure:** An attempt that could not finish. Partial feedback remains available for recovery; a failure must not replace a newer attempt or a completed evaluation.
